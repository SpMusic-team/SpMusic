# “未找到歌词”的样式未作适配

> 状态：已关闭（2026-08-13，验收通过）

## 问题描述

“未找到歌词”的样式未作适配（《如我所见-夜幕》）。

## 期望行为

未找到歌词时，提示应使用与当前界面一致的适配样式。

## 截图

（无）

## 修复说明

- 歌词空状态改用与歌词面板一致的配色与字体变量（`--player-lyrics-color`、`--player-lyrics-font-size` 等），标题、描述与操作按钮均按歌词字号体系适配。
- 空状态操作区提供“在第三方应用搜索歌词”按钮与设置按钮，样式与播放器控件体系统一。
