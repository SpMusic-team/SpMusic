# 按住进度条按钮时已播放进度条未变粗，释放时闪烁

## 问题描述

本缺陷包含三个问题：进度条颜色不是纯色；按住进度条按钮时，已播放部分的进度条宽度没有变粗；释放进度条按钮时，进度条会短暂闪烁。

## 期望行为

- 按住进度条按钮期间，已播放部分的进度条宽度变粗。
- 释放进度条按钮后，已播放部分的进度条宽度恢复原样。
- 释放进度条按钮时，进度条不应闪烁、变淡或发生进度回跳。
- 按住和释放时的宽度变化应即时生效，不应改变当前播放进度。

## 修复状态

- [x] 进度条使用纯色。
- [x] 按住进度条按钮时，已播放部分变粗；释放后恢复原样。
- [x] 释放进度条按钮时不闪烁、不变淡，进度值保持稳定。

## 验证结果

- 指针按住进度条按钮期间，仅已播放部分变粗。
- 指针释放、取消、失去捕获或窗口失焦后，进度条恢复原样。
- 指针拖出进度条后释放，按压样式仍能恢复，提交的进度值不会被反向取消。
- 释放进入短暂 seeking 状态时，进度条透明度保持稳定；其他禁用状态仍保留禁用视觉反馈。
- 轨道点击、悬停、键盘聚焦和键盘调节不会误触发按压样式。
