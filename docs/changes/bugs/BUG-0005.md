# 标题滚动未呈现“慢-快-慢”速度

> 状态：已关闭（2026-08-04，验收通过）

## 问题描述

滚动的“乒乓球”效果没有呈现“慢-快-慢”的速度。

## 期望行为

滚动动画应按“慢-快-慢”的节奏运行。

![BUG-0005 截图](../assets/bug-0004.png)

> 截图同 BUG-0004。

## 修复说明

- 正向滚动与反向滚动段改用 `ease-in-out` 缓动，两端慢、中间快，呈现“慢-快-慢”节奏。
- 停顿段保持匀速，停顿时长不受缓动影响。
