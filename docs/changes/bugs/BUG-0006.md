# 标题滚动间隔过快

> 状态：已关闭（2026-08-04，验收通过）

## 问题描述

滚动的间隔过快，应再加几秒间隔。

## 期望行为

滚动结束后停顿数秒，再开始下一次滚动。

![BUG-0006 截图](../assets/bug-0004.png)

> 截图同 BUG-0004。

- 提出日期：2026-08-03 03:25
- 来源：`更改项目.xlsx` 原表第 4 条拆分

## 修复说明

- 滚动方向结束后的停顿由 0.8s 加长到 3s（`scrollEdgePauseMs`）。
- 首次滚动前的起始延迟由 1s 加长到 2s（`scrollStartDelayMs`）。
- 若保存过自定义主题，其旧时间参数随主题持久化，需重置或重新导入该主题后生效。
