# 切换歌曲时短暂显示尚未加载歌曲状态

## 问题描述

真实播放歌曲时，两首歌曲切换期间会短暂显示“尚未加载歌曲”状态，大约两秒后才能正常播放。

## 期望行为

歌曲切换期间不应短暂显示“尚未加载歌曲”状态，应保持与正常切歌过程一致的播放反馈。
