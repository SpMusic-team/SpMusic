# 按下 Shift 时当前歌词错误显示黑色圆角框

## 问题描述

按下 Shift 键时，当前时间对应的歌词会错误显示黑色圆角框，且该框会持续跟随当前歌词，不符合设计预期。

## 期望行为

按下 Shift 键不应触发当前歌词的黑色圆角框，也不应产生持续跟随当前歌词的异常边框状态。
