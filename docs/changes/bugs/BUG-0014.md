# 更多信息面板第三行的歌曲信息与设计稿不符

## 问题描述

展开“更多”后，歌曲信息第三行的内容与设计稿不一致。来源要求该行按“音符图标 + 歌曲时长 + 分隔符 + 歌曲文件后缀”的顺序展示。

来源截图中第三行显示音符图标和 `04:08`，其后为复制图标；截图内未显示歌曲文件后缀。

## 期望行为

更多信息面板第三行应显示：`音符图标 歌曲时长 | 歌曲文件后缀`，具体样式与间距需对照已批准的设计稿确认。
