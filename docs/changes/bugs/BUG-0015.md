# 播放与暂停状态的图标尺寸和动效不一致

## 问题描述

播放器在播放与暂停状态之间切换时，中心按钮的图标尺寸及其与两侧按钮的间距不一致：播放状态下图标偏小、两侧间距偏大；暂停状态下图标偏大、两侧间距缩短。

来源同时指出，当前播放/暂停动效会使播放器的大部分组件变白，快速切换时会产生卡顿感，不符合预期。

## 期望行为

- 播放与暂停图标的尺寸及其与两侧按钮的间距应按设计稿统一校准。
- 状态切换效果应仅影响播放/暂停按钮及相关间距，不应使播放器的大部分组件变白。
- 快速播放、暂停切换时不应出现明显卡顿。
