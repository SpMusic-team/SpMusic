# 决策：v0.1 只做播放界面，虚构播放列表管理 UI 顺延到 v0.2

## 背景

原 v0.1 范围曾同时包含播放器界面、演示歌曲列表、UI-only 播放状态和最小 Tauri 通信验证。用户进一步明确版本拆分：v0.1 只做播放界面；v0.2 再做虚构播放列表管理 UI；原本的 v0.2 本地播放技术验证顺延。

## 决策

v0.1 调整为“播放界面”：

- 保留 SpMusic 项目身份展示。
- 保留播放界面、当前歌曲展示和基础播放控制。
- 使用假歌曲数据。
- 播放 / 暂停 / 上一首 / 下一首只改变前端 UI 状态。
- 不做虚构播放列表管理 UI。
- 不做本地文件读取、真实音频播放、媒体库、数据库、播放列表持久化或 `m3u8` 导入导出。
- 最小 Tauri 通信验证移出 v0.1，不作为当前版本验收项。

v0.2 调整为“虚构播放列表管理 UI”：

- 展示所有虚构播放列表。
- 展示选中播放列表内的虚构歌曲。
- 支持新增、编辑、删除和排序虚构播放列表。
- 支持歌单内歌曲排序、多选歌曲、加入到其他播放列表和从当前播放列表移除歌曲条目。
- 使用假播放列表和假歌曲数据。
- 不做文件读取、真实播放、持久化或导入导出。

原本的 v0.2 “本地播放技术验证”顺延为 v0.3。

## 影响

- v0.1 的验收重点是“可运行播放界面 + 清晰假歌曲边界”。
- 虚构播放列表管理 UI 不进入 v0.1，避免当前版本范围过大。
- 真实播放、文件读取和音频方案风险集中留到 v0.3 处理。

## 验收口径

- v0.1 可以展示播放界面和当前假歌曲。
- v0.1 可以展示假歌曲列表或等价歌曲区域，但不展示播放列表列表和播放列表详情。
- 播放 / 暂停 / 上一首 / 下一首只改变前端 UI 状态。
- v0.1 不读取用户文件，不播放真实音频，不写入持久化数据。
