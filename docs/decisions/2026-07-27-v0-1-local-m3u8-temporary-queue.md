# v0.1 本地 .m3u8 临时队列例外

## 决策

v0.1 允许一个窄范围例外：选择文件时，用户可以直接选择 `.m3u8` 文件。应用会把 `.m3u8` 中可解析、可访问、已受支持的本地音频文件转换为当前会话临时队列。

这不是产品级播放列表支持，也不是 HLS 支持。

## 范围

- 文件选择入口允许直接选择 `.m3u8`，并按文件内容构建临时队列。
- 忽略空行和 `#` 开头的 M3U / HLS 元信息行。
- 忽略 `http://`、`https://`、`ftp://`、`rtsp://`、`rtmp://` 等远程 URL。
- 支持 `.m3u8` 内相对播放列表所在目录的路径、本地绝对路径和 `file://` 路径。
- 直接选择 `.m3u8` 文件时，允许本地绝对路径指向播放列表所在目录之外的音频文件。
- 当前音频后端已支持扩展名的本地音频条目会进入队列；文件不存在时仍显示在队列中，并标记为不可用。
- 按 `.m3u8` 顺序播放时，遇到不可用条目会提示“歌曲未找到”，然后继续尝试下一首。
- 生成的队列只在当前会话中使用，不保存、不编辑、不导出。

## 不在范围

- 网络 HLS、直播流、分片 `.ts` / `.m4s`、缓存、重试、鉴权。
- 产品级播放列表创建、编辑、保存、删除、导入导出。
- 媒体库、数据库、文件监控、递归扫描。
- 选择文件夹自动发现 `.m3u8`。
- 相对路径越出 `.m3u8` 所在目录。

## 验收提示

- 选择普通音频文件时，现有同目录临时队列行为保持可用。
- 选择 `.m3u8` 文件时，队列按该文件内容顺序显示并加载第一首。
- `.m3u8` 中的本地绝对路径可以指向其他目录，并在文件存在且格式受支持时进入队列。
- `.m3u8` 中缺失的受支持本地音频文件会显示在队列里；播放遇到它时提示“歌曲未找到”并跳到下一首。
- `.m3u8` 中的远程 URL、HLS 标签、无效路径和越界路径不会进入队列。
