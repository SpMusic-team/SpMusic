# 最高评级页面实现

最高评级从现有全库歌曲与播放器评分表派生：五星模式收录 2～5 分，赞踩模式只收录 5 分（喜欢），按评分降序、标题、规范化路径排序。最低评级复用同一列表页，在两种模式中均只收录 1 分，并按标题与规范化路径稳定排序。展示所有符合条件的歌曲，不猜测 Poweramp 默认条数。不显示字母索引或手动排序。

页面复用最常播放的列表、虚拟化、封面、布局切换、搜索、选择、播放、随机播放、控制器和转场。原次数位置显示评级：五星模式显示对应数量星形，赞踩模式 5 分显示喜欢，1 分显示不喜欢，2～4 分不显示拇指；最高评级筛选排除 1 分，赞踩模式同时排除 2～4 分。模式读取 PlayerSurface 现有状态，不建立第二份偏好。喜欢图标来自本轮设计稿的原始 16px 本地资产，实心星形复用播放器的 Star48Filled 组件，其余图标复用现有页面。

星级标记采用三档固定尺寸，按用户要求缩小大、中两档后：大档每颗 8.832px，用于布局 0～4（全部封面网格及大、中封面行）；中档每颗 7.084px，用于布局 5～6（小封面行及双行无封面）；小档每颗 5.336px，用于布局 7～9。每档内星形尺寸保持一致，不再随封面连续缩放。赞踩图标独立使用三档尺寸，并按用户要求在此前对齐单星尺寸的基础上先增大三级、再增大两级，累计各增大五级（每级 1.748px）：布局 0～4 为 17.572px，布局 5～6 为 15.824px，布局 7～9 为 14.076px。拇指徽标内边距跟随其自身尺寸；星形尺寸保持不变，完整遮罩与不喜欢的旋转方向保持不变。播放次数样式不变。

播放来源支持 highest-rated 与 lowest-rated，纳入来源验证、快照名称、恢复路由、返回定位及封面预热；评级更改刷新分类成员，不重建正在播放的队列快照。最高评级的空状态随模式提示喜欢或 2～5 星歌曲，最低评级提示不喜欢（1 星）。Surface 保持评分模式的单一状态；Shell 提供候选集合，Panel 在排序、搜索、播放、随机及选择派生之前按当前模式筛选，切换模式立即更新页面但不改写现有播放队列。

评分现已通过统一的 track-ratings.v1 本地存储持久化，重启与同源重扫后保留星级及赞踩，取消评分也会保存。详细机制与存储失败行为见 docs/implementation/track-rating-persistence.md。没有增加标签写入、Rust 命令、依赖或权限。

Frontend 自检 npm run build 与 npm run lint 通过，交互与回归由 Test Agent 独立验证。
