# 播放界面五星评分模式

设置新增“评分模式”，默认“赞／踩”，可切换为“五星评分”。模式保存在本地偏好键 `spmusic.player.rating-mode.v1`；存储不可用时保留会话选择，异常值回退赞／踩。切换模式不修改评分。

评分以 `ratingsByTrackId` 中的 0～5 整数为单一来源，0 是未评分；5 派生喜欢，1 派生不喜欢，2～4 两者都不选中。当前评分延续原有会话生命周期，不写文件标签，不新增 Rust 命令或数据库。流的评分排序直接比较整数分数。

封面与更多叠加层共用 StarRating，通过绑定展示层 track.id 的回调写回同一来源，避免换曲动画旧封面误改新歌曲。按下展开至五颗星并选中命中分数；横向拖动按按下时固定的星形槽位坐标连续写入 0～5，松手收拢至当前分数颗实星，0 分为一颗空星。长按 400ms 在按下前评分为 5 时清零，否则设为 5；移动超过 8px 取消长按。方向键调整，Home、Delete、Backspace 清零，End 设为 5 分。Enter／Space 使用标准按钮交互。控件提供分值标签和当前精确分数的 aria-pressed。

保留动态歌曲封面。五星胶囊采用设计稿 72 高、左右 20 内边距、48 星形并在响应式布局中沿用对应缩放单位。轮廓星使用下载的 Figma 原始 SVG，选中星使用已有 Fluent 依赖的填充形态。颜色、圆角和阴影复用现有播放器主题变量。

实现自测 npm run build、npm run lint 通过；交互及视觉证据由独立 Test Agent 记录。媒体库“最高评价”分类留待后续实现。

## 参考视频评分动效

参考用户两段 2026-11-07 录屏：评分胶囊在静止时随星数收缩，按住时约 250ms 展开到五颗。宽度过渡复用现有 prototype-smart 时长及全局倍率，按压仅有 1.04 倍轻微放大，不复制系统触点圆圈。键盘聚焦时展开，焦点离开整组后收起；减弱动态效果或主题关闭动效时跳过过渡和放大。

指针由评分组独占 capture，down/move/up/cancel/lostcapture 都隔离封面拖动；取消只保留最后已写入的分数，不合成点击。捕获的 left/pitch 不随展开动画、父 value 更新或按压缩放重建。歌曲 key 变化卸载清理定时器，旧封面层离开 active 阶段即禁用评分并释放 capture，避免换曲后长按误写。模式切换卸载同样清理。更多叠加层沿用相同计数和手势行为，继续保持缩小、无背景且使用 inverse-primary。

## 收起评分的命中区与同分点按

用户反馈一星无法再次点按清零、收起后第三槽点击返回播放列表、更多评分操作失效。真实 Shell 基线分别确认：一星再次点按仍为 1；封面第三空槽命中 cover-actions 并打开播放列表；更多第三空槽命中 more-track-details，无评分 capture。对照从更多可见首星起手拖动能成功，排除 Dialog 普遍拦截手势。

修复将交互根固定为完整五槽，根保持透明，胶囊背景由独立伪元素收缩，内部星轨道只裁剪视觉内容。收起状态的空白槽仍由评分根命中并隔离封面事件。命中分数由固定 first.left／pitch 换算，不依赖 pointer capture 后变化的事件 target。点按记录按下前值与命中值；未移动、未长按且短点同值时清零，拖动和长按松手均不再执行同分切换。键盘 Enter／Space 同分也可清零。

修复后相同真实指针路径得到：一星再次点击为 0；封面第三空槽为 3 且播放列表保持关闭；更多第三空槽由评分根完成 down／capture／up／lostcapture 后为 3；原可见首星起手拖动保持有效。触摸及小尺寸独立回归由 Test Agent 记录。

## 封面操作统一等比例缩放

封面评分、更多、赞／踩统一消费封面宽度 C 的单位 U=C/990。更多为 72U×72U，赞／踩各为 106U×72U、间距 24U，图标均为 48U，左／右／底边距均为 12U。五星最大交互宽 330U=C/3 保持，静止视觉星数伸缩不变。更多按钮保留相对定位，以便按压涟漪定位在按钮内。

旧 responsive 样式曾分别使用 full／compact 固定像素及 horizontal／quarter 独立单位，导致更多在封面缩小时相对变大。现已删除这些重复规则及不再适用的封面操作 fallback 隐藏，统一由 cover-panel.css 定义；封面 container 在赞／踩与五星两模式均生效。播放／暂停引起封面宽变化时，整个操作组同步缩放。

该单位仅定义在封面操作 DOM 范围，更多叠加层在 Portal 中的缩小、透明背景、inverse-primary 五星以及原有按钮样式不受影响。三种 CSS 视口 2560×1440、1920×1080、1440×960 的播放中封面宽分别约 1062、796.5、602，对应更多按钮边长和评分高度约 77.24、57.93、43.78，图标边长约 51.49、38.62、29.19 CSS 像素。
