# 媒体库队列页面与添加到队列

独立媒体库队列使用 spmusic.library-queue.v1 保存轻量音源引用、独立 entryId、入队时间和已播时间。跨次操作允许同曲重复；同次批量操作按规范音源路径去重。添加保存成功后反馈实际加入数量，不主动切换播放来源；队列正在播放时原地追加其播放快照。

队列页面复用所有歌曲页面、十级卡片布局、封面缓存与选择面板。标题右侧显示已播数/队列总数，空队列显示“空”；斜杠和空文字中心与下方更多按钮中心对齐。页面、浮动操作条与播放控制器快捷栏均隐藏搜索。未播标记仅在队列根页面列表行中显示，复用 selection-panel/queue.svg，在评分之后显示，并消费评分的三档尺寸变量。其他分类和卡片网格不显示此标记。

文件夹、专辑、艺术家、专辑艺术家、作曲家、流派和年份复用原批量操作已有的完整集合展开。播放列表管理、列表歌曲、搜索结果和书签选择也接入添加到队列。提交时重新从当前授权来源解析真实音源；不把集合封面歌曲当作完整成员。

队列快照保留真实音频 trackId 与独立 entryId 顺序。普通加载和卡片预览分别维护待确认和已确认 occurrence 游标，过时响应及失败不会覆盖后续游标。队列随机按钮先洗牌 occurrence 顺序，再顺序播放。已播在接受真实 playing 状态的开始边沿记录，同路径既有未播条目一起更新；持续播放轮询不会把刚追加的同曲误标已播。恢复暂停会话不标已播。播放完成后继续保留记录，已播计数增加而总分母保持不变。

更多操作中的“清空队列”是真实手动动作，先成功写入空持久记录再更新内存；保存失败保留原状态并提示错误。清空独立队列不会删除音源或中断当前音频；活动队列播放快照置空，后续导航不会继续旧歌曲。预览与在途队列选择通过清空代次保护，防止旧异步结果复活已清空快照。空队列标题显示“空”。

静态资产复用：媒体库返回箭头 playlist-library/2d425.svg、随机 ce103.svg、播放 a31d0.svg、更多操作原有图标、队列分类已有 Arrow Step In 资产。歌曲封面由真实歌曲提供，未使用 Figma 的示例专辑封面。没有新增依赖、原生命令或权限。

验证：前端 build、lint 通过；独立测试 Agent 维护队列模型与真实 PlayerShell 浏览器用例，报告位于 docs/test/queue-library-verification.md。浏览器 native fixture 验证前端行为，不能替代真实音频设备的听音检查。
