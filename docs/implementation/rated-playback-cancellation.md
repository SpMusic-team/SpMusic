# 评级分类播放中取消当前评级

仅显式将当前歌曲已有评级设为 0，且真实播放来源为最高或最低评级时，执行分类移除后的选曲。浏览其他页面不影响来源判定；非当前歌曲、普通播放来源、评分模式切换、重扫和启动恢复均不自动切曲。评级修改仍由既有中央入口即时持久化。

Surface 将当前评分模式作为可选事件上下文传给 Shell，Shell 在提交取消操作前保存旧分类顺序，再用新评级表派生当前可播放成员：最高评级赞踩模式只含 5 分，五星模式含 2～5 分，最低评级只含 1 分。优先选择旧顺序中当前项之后仍存在的歌曲，末尾回绕至剩余第一项；重建队列为剩余真实分类成员。分类没有可播放歌曲时，按现有文件夹名称默认比较找到首个含可播放歌曲的文件夹，按文件夹歌曲默认标题顺序选择第一首，并以该文件夹成员建立 all-songs 来源的回退快照。

队列选择增加仅用于该操作的显式选项：自动播放保持取消前实际播放状态；暂停时只加载下一首。执行前比对当前曲目、后端 generation、选择活动序号及来源分类，失配即拒绝执行；后续异步步骤沿用已有请求序号隔离，新的用户选择优先。

该路径清除旧视觉 intent、预览令牌与候选封面，不创建 queue/next 入场 intent；新选择递增活动序号，通过现有非导航资源直接替换路径更新歌曲卡，避免入场翻转，不改变其他选曲的动效。没有增加计时器、全局动效关闭、依赖或 Rust 命令。

前端构建与 lint 检查结合 Test Agent 的下一首、末尾回绕、空分类回退、暂停保持、来源边界及逐帧动效验证。
