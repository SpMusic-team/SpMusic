# 发布计划

## 发布版本

v0.1 项目地基

## 目标

发布一个可运行、可验证、范围受控的 SpMusic 项目地基版本，用于后续真实播放、音乐库和播放列表能力的迭代起点。

## 发布内容

- SpMusic 项目身份和基础文档。
- 静态播放器主界面。
- 假歌曲队列。
- UI-only 播放状态切换。
- 最小播放器状态结构。
- Empty State 分支。
- 最小 Tauri command 通信验证。
- 基础工程检查清单。

## 不包含内容

- 真实音频播放。
- 媒体库和文件夹扫描。
- 数据库或持久化索引。
- 网络存储播放。
- 播放列表真实导入导出。
- 插件系统。
- 在线服务或账号系统。

## 发布前检查清单

- `npm run lint` 通过。
- `npm run build` 通过。
- 在 `src-tauri/` 下执行 `cargo check` 通过。
- `npm run tauri dev` 能启动桌面应用。
- 主界面显示 SpMusic，而不是模板 starter 内容。
- 播放器外壳展示至少 5 条假歌曲。
- 播放 / 暂停能切换 UI 状态。
- 上一首 / 下一首能切换当前假歌曲。
- 空队列分支已实现且可检查。
- 前端展示 Tauri command 返回结果或连接状态。
- README 描述当前能力和限制。

## 发布决策

只有当所有检查项通过，并且 PM Agent 完成 Sprint 复盘后，v0.1 才可视为可发布。
