# SpMusic 路线图

## 摘要

SpMusic 是本地优先的桌面音乐播放器。路线图原则调整为：先建立可运行的真实本地播放最小闭环，再继续扩展播放列表、媒体库、网络存储、外观自定义和插件能力。

## 版本规划

### v0.1 真实本地播放最小闭环

目标：在当前播放器界面基础上，实现一个可验证的真实本地音频播放链路。

范围：

- SpMusic 项目身份、README 和基础工程检查。
- 播放器界面、当前歌曲展示和基础播放控制。
- 最小 Tauri command 契约。
- Rust/Tauri 真实音频播放后端。
- 单个本地音频资源的播放、暂停、停止和进度状态。
- 前端接入真实播放 command。
- 真实播放验证报告。

不包含：

- 媒体库、文件夹扫描、数据库和持久化索引。
- 真实播放列表、播放历史、收藏和 `m3u8`。
- 网络存储播放。
- 真实频谱分析、高级 DSP、独占输出。
- 插件系统。

### v0.2 播放列表 UI 与播放体验收敛

目标：在真实播放最小闭环稳定后，补齐播放列表 UI 的可用体验。

候选范围：

- 虚构或轻量播放列表管理 UI。
- 当前队列展示、上一首 / 下一首联动和空状态。
- 播放错误、后端不可用和无音频资源时的 UI 状态。
- 根据 v0.1 后端反馈调整播放控制细节。

不包含：

- 完整媒体库扫描。
- 数据库持久化播放列表。
- 网络存储播放。

### v0.3 本地音乐库地基

目标：建立本地音乐库最小闭环。

候选范围：

- 选择本地文件夹。
- 扫描音频文件。
- 基础歌曲索引。
- 按歌曲浏览。
- 缺失元数据后备展示。
- 本地数据存储方案决策。

### v0.4 本地音乐库浏览与真实播放列表

目标：让本地音乐管理进入可日常使用的基础形态。

候选范围：

- 按艺术家、专辑浏览。
- 按文件夹范围过滤。
- 基础搜索。
- 收藏 / 喜欢。
- 播放历史列表。
- 基础播放列表。
- `m3u8` 导入导出策略。

### v0.5 网络存储播放

目标：支持用户自有网络存储中的音频资源。

候选范围：

- FTP / SMB / WebDAV 来源抽象。
- 网络文件浏览或引用。
- 流式播放能力评估。
- 离线与错误状态处理。

### v0.6 UI、性能与多语言

目标：强化 SpMusic 的核心体验差异化。

候选范围：

- 明暗模式。
- 基础主题切换。
- CSS token 白名单式视觉自定义。
- 多语言适配基础。
- 动画、动效 token 和视觉性能档位。
- 触控友好的关键交互。

### 后续高级能力

- 歌词。
- 专辑封面。
- 元数据编辑器。
- 智能播放列表。
- 独占音频输出。
- 收听记录可视化。
- Last.fm / Pano Scrobbler。
- 云同步适配。
- 自定义功能区。
- 可拆分、可置顶功能区。
- 插件增强体系。

## 范围护栏

- 基础播放、音乐库、播放列表和网络存储播放不应依赖插件。
- 插件只作为增强能力，不作为核心能力前提。
- SpMusic 不做在线音乐平台、在线曲库搜索、内容推荐或版权音乐服务。
- 每个版本必须有可验证的完成定义。
- v0.1 真实播放只做单资源最小闭环，不把媒体库、数据库或真实播放列表偷渡进来。
