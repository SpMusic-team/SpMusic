# SpMusic 路线图

## 摘要

本路线图基于 `docs/requirements/总需求分析.md`。路线图的原则是先建立可运行的播放界面，再逐步进入虚构播放列表管理 UI、真实播放、音乐库、真实播放列表、网络存储、高级 UI 和扩展能力。

## 版本规划

### v0.1 播放界面

目标：摆脱模板项目状态，使用假数据建立可运行、可验证的 SpMusic 播放界面。

范围：

- SpMusic 项目身份和 README。
- 播放界面：当前歌曲信息和基础播放控制。
- 假歌曲数据。
- UI-only 播放状态。
- 基础验证命令和发布检查清单。

不包含：

- 真实音频播放。
- 本地文件读取。
- 最小前后端通信验证。
- 媒体库。
- 数据库。
- 网络存储。
- 虚构播放列表管理 UI。
- 播放列表真实创建、编辑、删除、导入导出。
- 插件系统。

### v0.2 虚构播放列表管理 UI

目标：在播放界面之后，使用假数据建立可运行、可验证的虚构播放列表管理 UI。

候选范围：

- 展示所有虚构播放列表。
- 展示选中虚构播放列表内的虚构歌曲。
- 新增、编辑、删除虚构播放列表。
- 调整虚构播放列表显示顺序。
- 按默认顺序、歌曲名称和时长查看歌单内歌曲。
- 默认排序模式下手动调整歌单内歌曲顺序。
- 多选歌曲并加入到其他一个或多个虚构播放列表。
- 从当前虚构播放列表中移除一个或多个选中歌曲条目。
- 删除播放列表确认提示。
- 空播放列表和空歌曲列表 Empty State。
- 播放列表管理 UI 与 v0.1 播放界面的当前歌曲状态联动。

不包含：

- 真实音频播放。
- 本地文件读取。
- 媒体库。
- 数据库。
- 跨应用重启持久化播放列表修改。
- 播放列表真实导入导出。
- `m3u8` 支持。
- 删除真实歌曲文件。

### v0.3 本地播放技术验证

目标：在播放界面和虚构播放列表管理 UI 之后，评估并实现第一条真实本地音频播放链路。

候选范围：

- 音频方案评估和架构决策。
- 单文件本地音频播放。
- 播放 / 暂停 / 停止。
- 基础音量和进度状态。
- 格式支持边界记录。

不包含：

- 完整媒体库。
- 高级 DSP。
- 独占输出。
- 网络存储播放。

### v0.4 本地音乐库地基

目标：建立本地音乐库最小闭环。

候选范围：

- 选择本地文件夹。
- 扫描音频文件。
- 基础歌曲索引。
- 按歌曲浏览。
- 缺失元数据后备展示。
- 本地数据存储方案决策。

### v0.5 音乐库浏览与播放列表

目标：让本地音乐管理进入可日常使用的基础形态。

候选范围：

- 按艺术家、专辑浏览。
- 按文件夹范围过滤。
- 基础搜索。
- 收藏 / 喜欢。
- 播放历史列表。
- 基础播放列表。
- `m3u8` 导入导出策略。

### v0.6 网络存储播放

目标：支持用户自有网络存储中的音频资源。

候选范围：

- FTP / SMB / WebDAV 来源抽象。
- 网络文件浏览或引用。
- 流式播放能力评估。
- 离线与错误状态处理。

### v0.7 UI、性能与多语言

目标：强化 SpMusic 的核心体验差异化。

候选范围：

- 明暗模式。
- 基础主题切换。
- 多语言适配基础。
- 动画和视觉性能档位。
- 触控友好的关键交互。

### 后续高级能力

目标：在基础播放器稳定后扩展高级体验。

候选范围：

- 歌词。
- 专辑封面。
- 元数据编辑器。
- 智能播放列表。
- 独占音频输出。
- 收听记录可视化。
- Last.fm / Pano Scrobbler。
- 云同步适配。
- 自定义功能区。
- 可拆分、可置顶功能区。
- 插件增强体系。

## 范围护栏

- 基础播放、音乐库、播放列表、网络存储播放不应依赖插件。
- 插件只作为增强能力，不作为核心能力前提。
- SpMusic 不做在线音乐平台、在线曲库搜索、内容推荐或版权音乐服务。
- 每个版本必须有可验证的完成定义，不能以最终愿景替代当前版本范围。
