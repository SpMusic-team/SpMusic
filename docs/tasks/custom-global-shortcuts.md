# 任务：自定义全局快捷键设置

## 背景与目标

用户需要在应用处于后台时控制播放，并在设置中自定义按键。用户已授权本次实现；本任务仅覆盖五项全局快捷键、保存持久化、恢复默认和冲突反馈。

| 操作 | 默认快捷键 |
| --- | --- |
| 上一首 | Ctrl + Alt + ← |
| 下一首 | Ctrl + Alt + → |
| 提高音量 | Ctrl + Alt + ↑ |
| 降低音量 | Ctrl + Alt + ↓ |
| 播放 / 暂停 | Ctrl + P |

播放 / 暂停采用现有播放器切换语义；上下首、音量步长与边界沿用现有播放控制行为。

## 优先级与非目标

P1：用户明确要求本次交付的设置能力。非目标为新增其他快捷键操作、改造音频引擎、添加在线服务或迁移 UI 基底。

## 涉及模块与负责 Agent

| Agent | 责任与写入边界 |
| --- | --- |
| Architecture Agent | 实现前审查原生注册、持久化、播放动作与前后端错误契约；默认只读 |
| Frontend Agent | 设置入口、五项按键编辑、保存 / 恢复交互、错误展示与已有播放控制集成；仅写分配的 `src/` 文件 |
| Rust/Tauri Agent | 原生后台快捷键注册、更新和清理，设置读写、注册错误传播；仅写分配的 `src-tauri/` 文件 |
| Test Agent | 独立核验验收标准和回归结果；默认只读，测试产物路径由主 Agent 单独分配 |
| 主 Agent | 明确每个文件的唯一写入者，整合实现并执行仓库级最终验证 |

前后端并行写入范围必须互不重叠；共享配置、依赖和锁文件由指定 Owner 顺序修改。各 Agent 不撤销其他人的改动。

## 输入、输出与依赖

- 输入：用户请求、当前设置和播放控制实现、Architecture Agent 审查后的契约。
- 输出：可使用的设置界面、原生全局快捷键及持久化实现、验证证据和实际限制说明。
- 依赖：先完成架构审查，确认命令 / 事件、存储归属、注册生命周期及失败恢复规则，再开始业务实现。依赖新增仅在审查批准的必要范围内执行。

## 验收标准

- 设置中显示五项动作与默认组合，允许分别修改；按键组合展示与原生实际注册一致。
- 首次启动按表中默认组合注册；切到其他应用或最小化播放器后，五项操作仍能控制现有播放队列与音量。
- 保存成功后新组合生效，被替换的组合不再触发该动作；退出并重新启动后，设置与实际注册保持一致。
- 恢复默认并保存后，五项组合与表中一致；重启后仍保留默认组合。
- 配置内重复组合和无效输入被明确拒绝。系统或其他应用已占用组合时，展示对应操作和失败原因，不显示保存成功。
- 注册、保存或恢复失败时，界面如实反映有效配置；不得以吞错或仅更新显示值伪造成功，既有可用快捷键的保留 / 恢复符合审查后的契约。
- 一次按下只触发一次动作，释放不重复触发；退出后注销原生快捷键。空队列和音量上下限遵守现有播放器行为，无前后端状态分歧。
- `npm run build`、`npm run lint`、`cargo check --manifest-path src-tauri/Cargo.toml` 通过；必要的新增回归测试通过。
- Test Agent 独立验证默认、修改、保存重启、恢复、后台控制和失败分支，并报告实际执行证据；未实际执行的桌面交互明确标为待验，不等同于通过。

## 风险与文档更新

- 默认组合可能与系统或其他应用冲突，必须真实报告注册失败，并允许用户改用其他组合。
- 编辑、保存、注册与重启恢复涉及异步生命周期，需避免重复监听、半套注册或错误成功提示。
- 浏览器预览无法替代原生后台快捷键验收，需记录桌面运行环境与可验证范围。
- PM Agent 维护本任务状态；验证证据由主 Agent 汇总，Test Agent 在明确分配时写测试报告。本次不扩写其他规划文档。
