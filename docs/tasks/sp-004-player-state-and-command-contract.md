# 任务：播放器状态与假歌曲结构

## 背景

v0.1 只做播放界面，需要前端有最小播放器状态结构和假歌曲结构，避免把播放列表、真实音频播放、媒体库或持久化播放列表提前引入。

## 目标

定义 v0.1 所需的最小前端播放器状态和演示歌曲结构。

## 非目标

- 不设计真实音频引擎。
- 不设计 Tauri command。
- 不设计虚构播放列表管理 UI 或演示播放列表结构。
- 不设计持久化、媒体扫描、真实播放列表或网络存储。

## 负责 Agent

Architecture Agent

## 涉及文件 / 模块

- `docs/architecture/player-state-and-command-contract.md`
- `src/App.tsx`

## 验收标准

- 契约定义假歌曲渲染所需字段。
- 契约定义播放器状态字段，例如当前歌曲 ID、播放状态和当前歌曲列表。
- 契约定义空歌曲列表的状态表达。
- 契约明确不包含真实播放、音量、进度、媒体库、Tauri command 和持久化字段。

## 备注

该任务阻塞前端 UI 原型实现。
