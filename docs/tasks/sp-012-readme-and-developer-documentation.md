# 任务：README 与开发文档

## 背景

README 需要反映 SpMusic 项目身份，而不是模板 starter 内容。

## 目标

更新 README 和相关说明，让协作者理解项目身份、当前能力、限制和验证命令。

## 非目标

- 不把延期能力写成已实现。
- 不修改构建脚本或依赖。

## 负责 Agent

Documentation Agent

## 涉及文件 / 模块

- `README.md`
- `docs/roadmap.md`
- `docs/release-plan.md`
- `docs/sprint-plan.md`

## 验收标准

- README 标题和摘要识别为 SpMusic。
- README 列出本地开发命令。
- README 链接需求、路线图、Sprint 计划和发布计划。
- README 明确说明 v0.1 限制。
- README 不声称已支持真实音频播放或媒体库。
