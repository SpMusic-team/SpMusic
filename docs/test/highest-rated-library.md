# 测试报告：最高评级页面

## 摘要

独立模型与浏览器验收通过。浏览器使用真实 PlayerShell、PlayerSurface 及歌曲卡片，只替换原生传输；本结论覆盖前端页面与队列接入，不代表真实音频设备验证。

## 范围

评分 2～5 筛选、评分降序、标题和路径稳定次序、模式显示、选择、搜索返回、媒体库返回、评级变化、播放快照和随机播放；最常播放相邻回归。

## 实现交付与证据完整性

- 实现 Owner：Frontend Agent。
- 修改范围：最高评级派生模型、库视图模型、页面接线、共享卡片评级徽标、既有队列来源扩展。
- 复现基线：新功能无缺陷基线；视觉检查另发现星形裁切，增加失败断言后交回前端修正并复验。
- 已知证据：评级沿用既有内存状态；5 为喜欢、1 为不喜欢，2～4 无拇指徽标。
- 因果链：评级状态更新 → 派生集合重算 → 同一歌曲卡片按当前模式显示；播放保存独立队列快照。
- 证据缺口：未使用 Tauri 实机音频输出；截图夹具歌曲无真实封面，封面位显示既有占位。

## 根因与因果链反证

初版 48×48 星形 SVG 被用于 16×16 mask，默认 `mask-size:auto` 导致裁切。独立截图发现后，回归断言确认 computed maskSize 为 auto；前端为评级 glyph 增加 contain 后同一断言通过，截图显示完整星形。排除了评分数量错误的替代假设：初版 DOM 数量正确但图形裁切，修正仅作用于 mask 缩放。

## 跨层契约

新增最高评级来源沿用现有 TypeScript 队列契约；无新增原生命令、事件、权限或序列化字段。真实壳层夹具验证队列内容和来源页面返回；未把模拟传输当成真实设备证明。

- 降为 1 分立即移出页面，已开始播放的队列快照保持不变；随机播放仅包含当前合格歌曲。
- 既有最常播放测试覆盖计数、tile/compact 多布局、选择、队列、随机和重载通过。

## 性能 / 时序

本次未声明性能优化，未做性能基准。评级改变的同步派生与队列快照隔离由浏览器检查覆盖；音频异步传输为受控夹具。

## 发现

初轮验证漏检了已评分星形应为实心的语义，用户指出后补充复验。前端复用 Star48Filled；独立浏览器检查 SVG 中心点确实位于填充区域、与封面比例一致的几何，以及列表和 tile 数量，并视觉复核截图。全套最高评级验收再次通过，未发现剩余阻塞问题。

## 风险

评级仍沿用既有内存状态，重启后的评级持久化不属于本次验证结论。未验证真实大曲库、音频硬件及真实用户封面。最高评级当前展示全部合格曲目，无数量上限设置。

非临时缓解；当前星形已改用实心 SVG，旧 mask 断言替换为填充区域与封面比例断言。
